CÓMO USAR ESTE ARCHIVO
=======================

1) Abre "quieres_salir_conmigo.html" con doble clic (se abre en tu
   navegador). El botón "No" se escapa cada vez que el cursor se
   acerca o lo tocas, y el "Sí" va creciendo. En el celular, el
   dedo lo mueve apenas lo toca.

2) Para cambiar los textos, abre el archivo con un editor de texto
   (clic derecho -> Abrir con -> Bloc de notas / TextEdit / VS Code)
   y busca, casi al final, el bloque que dice:

       const PREGUNTA = "...";
       const MENSAJE_FINAL = "...";
       const FRASES_HUIDA = [ ... ];

   - PREGUNTA: la pregunta principal de la tarjeta.
   - MENSAJE_FINAL: lo que aparece cuando por fin le da "Sí".
   - FRASES_HUIDA: las frases que van cambiando cada vez que el
     botón "No" se escapa (puedes agregar o quitar las que quieras).

   Guarda el archivo y vuelve a abrirlo para ver los cambios.
